# 🎪 대동제 & 해커톤 로그 정규표현식 추출기

2026 전주대학교 대동제와 밤샘 해커톤을 함께 운영하며 쌓인 로그 파일에서 필요한 정보만 **정규표현식(regular expression)** 으로 뽑아내는 파이썬 프로그램입니다.

로그에는 일부러 넣은 **함정 데이터**가 섞여 있습니다. 형식이 틀린 이메일, 자릿수가 모자란 번호, gitlab 주소, 지난해 쿠폰, 카드·현금 세부 내역 같은 것들입니다. 이런 값은 빼고 **조건에 맞는 값만** 정확하게 추출하는 것이 목표입니다.

> 강의자료 **[07. 람다와 정규표현식 2]** 에서 배운 함수만 사용했습니다.

## ▶️ 실행 방법

```bash
cd festival_regex
python -X utf8 festival_regex.py
```

- Python 3.x 표준 라이브러리(`re`, `functools`, `os`)만 사용하므로 따로 설치할 것이 없습니다.
- `-X utf8` 옵션은 Windows 콘솔에서 한글이 깨지지 않게 해 줍니다.
- 로그 파일은 스크립트와 같은 폴더에서 자동으로 찾습니다.

## 📚 강의자료에서 사용한 함수

| 함수 / 기능 | 설명 | 이 프로그램에서 쓴 곳 |
|---|---|---|
| `re.compile()` | 패턴을 미리 컴파일해 재사용 | 모든 패턴 (6개) |
| `findall()` | 매칭된 문자열을 리스트로 반환 (그룹이 2개 이상이면 **튜플 리스트**) | 이메일, 전화번호, 학번·학과, GitHub, 쿠폰 |
| `finditer()` | 매칭 결과를 match 객체로 하나씩 반환 | 부스별 매출 |
| `match()` | 문자열 **처음부터** 매칭 검사 | `is_full_match()`로 제외 값 검증 |
| `search()` | 문자열 전체에서 **처음 매칭되는 곳** 검색 | 첫 번째 매출 줄 찾기 |
| `group()`, `start()`, `end()`, `span()` | match 객체 메서드 | 매출 추출, 위치 출력, 전체 일치 검사 |
| `re.VERBOSE` | 패턴 안에 공백과 주석 허용 | 이메일 패턴 |
| `re.MULTILINE` | `^`가 각 줄의 시작에 매칭 | 매출 패턴 |
| `lambda` + `map()` | `'1,350,000'` → `1350000` 변환 | 매출 문자열을 정수로 |
| `lambda` + `filter()` | 조건에 맞는 요소만 남기기 | 150만 원 이상 매출 부스 |
| `lambda` + `functools.reduce()` | 누적 계산 | 총매출 합계 |

## 🔍 추출 항목과 정규표현식

### [1] 유효한 이메일 주소

```python
EMAIL_PATTERN = re.compile(r"""
    [A-Za-z0-9._]+      # 아이디: 영문, 숫자, 점(.), 밑줄(_)이 1개 이상
    @                   # 골뱅이
    [A-Za-z0-9-]+       # 도메인 첫 부분: @ 바로 뒤에 반드시 문자가 있어야 함
    \.                  # 점
    [A-Za-z.]+          # 나머지 도메인: ac.kr / com 등
""", re.VERBOSE)
```

- `re.VERBOSE`를 써서 패턴을 줄마다 나누고 주석을 달았습니다.
- **제외 대상:** `hyunwoo@.ac.kr`
  - `@` 바로 뒤의 `[A-Za-z0-9-]+`는 글자가 **1개 이상** 있어야 합니다.
  - `@.`처럼 바로 점이 오면 매칭되지 않습니다.

### [2] 010 휴대전화 번호

```python
PHONE_PATTERN = re.compile(r'010[-. ]\d{4}[-. ]\d{4}')
```

- 구분자 `[-. ]`는 하이픈, 점, 공백 중 하나를 뜻합니다.
- **제외 대상:**
  - `063-3290-1114`, `02-...`: 010으로 시작하지 않습니다.
  - `010-123-4567`: 가운데가 3자리라서 `\d{4}`에 맞지 않습니다.

### [3] 학번과 학과 (튜플)

```python
STUDENT_PATTERN = re.compile(r'\[(202\d{6})\s*/\s*([^\]]+)\]')
```

- `202` 뒤에 숫자 6자리가 오므로 **정확히 9자리**입니다.
- 괄호 그룹이 2개라서 `findall()`이 `(학번, 학과)` **튜플 리스트**를 돌려줍니다.
- `[^\]]+`는 닫는 대괄호 `]`가 나올 때까지의 학과명입니다.
- **제외 대상:**
  - `20261122`: 8자리라서 `\d{6}`을 채우지 못합니다.
  - `999900000`: 202로 시작하지 않습니다.

### [4] GitHub 저장소 링크 & 2026 축제 쿠폰

```python
GITHUB_PATTERN = re.compile(r'https?://github\.com/[\w.-]+/[\w.-]+')
COUPON_PATTERN = re.compile(r'FEST-2026-[A-Z0-9]{4}')
```

- `https?`의 `s?`는 http와 https를 모두 받습니다.
- `github\.com/계정/저장소` 형태만 매칭합니다.
- **제외 대상:**
  - `https://gitlab.com/...`: github.com이 아닙니다.
  - `FEST-2025-OLD9`: 2026년 쿠폰이 아닙니다.

### [5] 부스별 매출과 총매출

```python
SALES_PATTERN = re.compile(r'^- (.+) 매출: ([\d,]+)원', re.MULTILINE)
```

- `re.MULTILINE`을 줘야 `^`가 파일 전체의 시작이 아니라 **각 줄의 시작**에 매칭됩니다.
- 그룹 1은 부스명, 그룹 2는 콤마가 들어간 금액입니다.
- `finditer()`로 match 객체를 하나씩 받아 `group(1)`과 `group(2)`를 꺼냅니다.
- 금액 변환과 합계:

  ```python
  amounts = list(map(lambda x: int(x.replace(',', '')), amounts))   # 문자열 → 정수
  total   = reduce(lambda x, y: x + y, amounts)                     # 총매출
  ```

- **제외 대상:** 카드·현금 세부 내역과 5,000원 쿠폰 할인 금액
  - 이 줄들은 `"- 부스명 매출: "` 형식으로 시작하지 않습니다.
  - 그래서 **부스 총매출만** 합산됩니다.

## ✅ 제외 값 검증

`match()`와 `end()`로 문자열 **전체**가 패턴과 일치하는지 확인하는 함수를 만들었습니다.

```python
def is_full_match(pattern, s):
    m = pattern.match(s)
    return m is not None and m.end() == len(s)
```

이 함수에 일부러 넣은 함정 데이터를 넣어 보고, 전부 `제외`로 나오는지 확인합니다.
